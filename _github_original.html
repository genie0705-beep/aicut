WHY 에이컷

영상 담당 인력 없이도
매월 꾸준히 업로드할 수 있습니다

정기 편집 파트너 에이컷(AICUT)이 인력·시간·퀄리티 문제를 한 번에 해결합니다

이런 상황이라면
에이컷이 필요합니다

  • 👥
    영상 전담 인력 고용이 부담스럽다
    정규직 영상 PD 한 명 연봉이 3,000만원 이상. 에이컷은 필요한 만큼만, 고용 없이 전담 에디터를 운영합니다.
  • ⏰
    마케터·기획자가 편집까지 담당하고 있다
    본업에 집중해야 할 팀원이 편집에 시간을 쏟는 구조. 월 정기 계약으로 편집 업무를 완전히 외부화합니다.
  • 📉
    프리랜서·외주 퀄리티가 들쭉날쭉하다
    매번 새 편집자와 브리핑, 소통 비용, 결과물 불확실성. 에이컷은 전담 에디터가 브랜드를 학습해 일정한 퀄리티를 유지합니다.

자주 묻는 질문

궁금한 점을 클릭해서 확인해보세요

📌 계약 · 요금
최소 계약 기간이 있나요?+
최소 계약 기간은 없습니다. 월 단위로 계약하며 언제든 해지 가능합니다. 다음 달 결제 전에 해지 의사를 알려주시면 됩니다.
계약 중간에 편수를 변경할 수 있나요?+
가능합니다. 다음 달 갱신 시 플랜 변경을 요청해주시면 STARTER ↔ STANDARD 자유롭게 조정됩니다.
이번 달 편수를 다 못 쓰면 이월되나요?+
이월은 되지 않습니다. 월 단위로 리셋되며, 추가 편수는 건당 추가 요금이 발생합니다.
📌 작업 방식
원본 영상은 어떻게 전달하나요?+
카카오톡 채널 또는 구글 드라이브로 전달해주시면 됩니다. 대용량 파일도 문제없이 수신 가능합니다.
납품은 얼마나 걸리나요?+
평균 납기는 D+1 (영업일 기준 익일)입니다. 분량이 많거나 복잡한 작업의 경우 사전 협의 후 조정됩니다.
수정은 몇 번까지 가능한가요?+
STARTER는 편당 2회, STANDARD는 편당 3회입니다. 수정 항목 제한 없이 자유롭게 요청 가능합니다.
편집 스타일을 지정할 수 있나요?+
가능합니다. 레퍼런스 영상을 공유해주시면 해당 스타일로 맞춰드립니다. 브랜드 가이드(컬러, 폰트, 인트로 등)도 저장해두고 매번 적용합니다.
📌 에디터 · 품질
담당 에디터가 매번 바뀌나요?+
아닙니다. 계약 시 전담 에디터가 배정되며 같은 에디터가 지속적으로 담당합니다. 처음부터 다시 설명할 필요가 없습니다.
에디터와 직접 소통할 수 있나요?+
모든 소통은 에이컷 담당자를 통해 진행됩니다. 고객님은 카카오톡으로 편하게 요청해주시면 담당자가 에디터에게 정확히 전달합니다.
샘플 편집을 먼저 받아볼 수 있나요?+
가능합니다. 계약 전 샘플 1편을 먼저 편집해드립니다. 퀄리티 확인 후 계약 여부를 결정하셔도 됩니다.
📌 장르 · 작업 범위
어떤 종류의 영상을 편집할 수 있나요?+
숏폼(릴스/쇼츠/틱톡), 유튜브 롱폼, 인터뷰, 강의, 제품 리뷰, 광고 소재, 브랜드 영상 등 대부분의 영상 콘텐츠 편집이 가능합니다.
자막, 썸네일도 포함되나요?+
자막은 기본 포함입니다. 썸네일 디자인은 STANDARD 이상 플랜에 포함됩니다.
대량 의뢰도 가능한가요?+
가능합니다. 월 100편 이상 대량 의뢰는 ENTERPRISE 플랜으로 전담팀을 구성해 처리합니다. 체험단 업체, 광고대행사, 이커머스 브랜드 대량 수주 경험이 있습니다.

네, 가능합니다. 새 의뢰 접수 시 증빙 서류 선택에서 세금계산서를 선택하시고 사업자번호를 입력해 주세요.
