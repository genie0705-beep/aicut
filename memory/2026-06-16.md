### 네이버 SmartEditor SE4 자동화 트러블슈팅

**문제:** SmartEditor가 React SE4(PostWriteForm)로 업그레이드되어 이전 방식(postwrite iframe 접근)이 막힘
- `keyboard.type()` 직접 입력 → React가 가로채서 무시
- `setDocumentData()` API → 데이터는 저장되나 React가 화면 미표시 (발행 시 정상 반영)
- `contenteditable` 요소가 화면 밖(-9999)에 숨겨져 있음

**해결:** 클립보드 붙여넣기(Ctrl+V) 방식 — React paste 이벤트가 정상 트리거됨
- `navigator.clipboard.write()`로 HTML 클립보드 복사
- SmartEditor가 자체 HTML 파서로 처리 → 정상 렌더링
- 테스트 결과: `hasContent: true` ✅

**확정된 자동화 방식:**
1. 제목 → `setDocumentTitle()` API
2. 본문 → 클립보드 HTML → `Ctrl+V` 붙여넣기
3. 이미지 → `waitForEvent('filechooser')` → `setFiles()`
4. 저장 → 저장 버튼 `.click()`
