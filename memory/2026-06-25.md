## 🔬 SE4 1.77.0 텍스트 입력 방식 확정

### 문제
- SE4 1.77.0 업데이트로 클립보드 paste(Ctrl+V)가 텍스트 입력에서 React에 차단됨
- `keyboard.type()` → React 무시
- `execCommand('insertText')` → contenteditable이 화면 밖(x:-9999)에 있어 DOM만 변경, SE4 데이터 레이어 미반영
- `ClipboardEvent` dispatch → 보안 제약으로 실제 데이터 미포함

### 해결: `SmartEditor._editors['blogpc001']._editingService.write(text)`
- **이게 유일하게 정상 동작하는 SE4 공식 입력 API**
- 사람이 직접 타이핑하는 것과 동일한 경로로 SE4 데이터 레이어에 전달됨
- `writeTextWithSoftLineBreak(text)`로 \n 단위 문단 입력 가능
- `lineBreak()`로 줄바꿈 가능

### 핵심: 호출 순서
1. `resetDocumentData()` — 에디터 초기화
2. `setDocumentTitle('제목')` — 제목 설정
3. **`focusToFirstComp()`** ← 반드시 먼저 호출 (이거 안 하면 write()에서 `getText` undefined 오류)
4. `writeTextWithSoftLineBreak(text)` 또는 `write()` + `lineBreak()`

### 이미지 붙여넣기
- 클립보드에 `image/png` MIME 타입으로 적재 → contenteditable focus + 커서 끝 → `page.keyboard.press('Control+v')`
- SE4 1.77.0에서도 이미지 paste는 정상 동작 확인됨 (텍스트 paste만 차단)

### 4-0-1 구조 (224324428697 방식 재현 성공)
- **순서:** write() 텍스트 → 이미지 paste → write() 텍스트 → 이미지 paste → ... (5회 반복)
- 최종: image→title→text→image→text→image→text→image→text→image→text→image→text (13컴포넌트)
- 정확한 image→text 번갈아 배치 구조 완성
