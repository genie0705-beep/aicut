## 🔧 SE4 에디터 자동화 중요 발견

### "작성중인 글이 있습니다" 팝업 처리
- **HTML 커스텀 모달** (브라우저 네이티브 dialog 아님)
- "취소" 버튼: `<SPAN class="se-cover-button-discard-position">` — **위치 (0,0), 크기 0x0**
- 마우스 클릭 ❌ → `element.click()` (JavaScript) 필수 ✅
- `discard` = 이전 임시글 폐기 + 새 글 작성

### 저장 API (RabbitTempPostWrite.naver)
- POST 요청, 응답 `{"isSuccess":true,"result":{"logNo":...}}` → **저장 안 됨 (데이터 누락)**
- 저장 버튼 클릭 시 SE4가 React 상태 기준으로 documentModel 전송
- clipboard 방식: 본문이 하나의 text(39 paragraphs)로 통합됨, charCount 1~14자로 빈 상태 저장
- setDocumentData 방식: 본문 데이터 정상 설정(21 comps, 166자)되나 **React가 변경 감지 못함** → 저장 버튼 비활성화
- 해결: setDocumentData로 설정 후 **발행 버튼** 사용 (발행은 다른 API, 정상 동작 예상)
