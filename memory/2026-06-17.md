## SmartEditor SE4 자동화 트러블슈팅 (재확인)
- **작동 확인된 방식:** navigator.clipboard.write(Blob HTML) → 마우스클릭(510,400) → Ctrl+V → 저장
- **실패한 방식:** setDocumentData(html), contenteditable.innerHTML, execCommand('insertHTML'), KeyboardEvent 디스패치
- **원인:** SmartEditor Papyrus Document Model이 React SyntheticEvent(trusted paste)만 인식. CDP context에서 clipboard write는 브라우저 권한/정책에 따라 일관성 없음.
- **해결:** 재시도하면 성공할 때도 있고 실패할 때도 있음. 가장 안정적인 방법은 수동 Ctrl+V.
