## 기술 발견: SmartEditor SE4 자동화
- `setDocumentTitle('...')`: 제목 설정 API ✅
- `page.keyboard.type(text, {delay: 2})`: 키보드 입력으로 본문 작성 ✅ (delay 없이 type() 하면 React가 이벤트 놓침)
- `page.keyboard.insertText()`: React SE4에서 미지원 ❌
- `setComponentList()`, `setDocumentData()`: 내부 validation 실패로 사용 불가 ❌
- `getDocumentData()`: 읽기 전용으로는 사용 가능 ✅
- 이미지 업로드: SE4 사진 버튼이 CDP filechooser 이벤트 트리거 안 함 ❌
- 해시태그: input 태그 찾아 직접 value 설정 + keydown Enter 이벤트 디스패치 ✅
- 정렬 버튼: 드롭다운 UI 클릭 방식, 전체 선택 후 적용 시 선택 풀림 문제 있음
