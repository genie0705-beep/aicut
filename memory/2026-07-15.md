## 🚨 네이버 블로그 SE4 에디터 자동화 교훈 (매우 중요!)

### ❌ 절대 금지
1. **execCommand('copy') + execCommand('paste')** → SE4가 무시함 + **저품질 유발**
2. **execCommand('insertHTML')** → 작동 안 함
3. **setDocumentData()만으로는 canvas 업데이트 안 됨**

### ✅ 유일하게 작동하는 방식
1. `SmartEditor._editors['blogpc001'].setDocumentTitle('제목')` — 제목 설정
2. `ed.getDocumentData()` → `data.document.blocks` 배열 직접 구성
3. 블록 구조: `{ type: 'heading2'|'heading3'|'paragraph', text: '내용', style: { textAlign: 'center' } }`
4. `ed.setDocumentData(data)`로 데이터 설정
5. **canvas.innerHTML 직접 업데이트 (필수!)**
6. 저장 버튼 클릭

### Strong 키워드 적용
- `text` 필드에 `<strong>키워드</strong>` HTML 태그 직접 삽입 가능
- SE4가 HTML을 그대로 렌더링함

### 이미지 업로드
- 자동화 시 canvas 상태 깨짐 위험
- 안전하게는 정이사님이 직접 "사진 추가" 버튼으로 업로드

### CTA 링크
- SE4가 `<a>` 태그 필터링해서 제거
- blocks에 link/href 속성 추가해도 저장 시 무시됨
- 텍스트 URL로만 표시 가능

### 데이터 구조 (SE4)
```javascript
{
  document: {
    version: "2.10.2",
    blocks: [
      { type: 'paragraph', text: '내용', style: { textAlign: 'center' } },
      { type: 'heading2', text: '제목', style: { textAlign: 'center' } },
    ]
  },
  documentId: "..."
}
```
