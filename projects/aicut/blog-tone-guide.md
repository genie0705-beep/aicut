## 1. 문장·문체 패턴

| 요소 | 패턴 |
|---|---|
| 문장 길이 | 짧음 (한 문장 1줄, 2~3어절 컷) |
| 줄바꿈 | 매우 잦음 — 한 문장에서도 의미 단위로 줄바꿈 |
| 종결어미 | "~다" 평서체 (단정형). 존댓말 X, 반말도 X. **기사·칼럼체** |
| 어조 | 차분·단정·결론지향. 감탄·이모티콘 남발 X |
| 인용 | 큰따옴표로 고객 멘트 강조 ("결과물이 브랜드 같지 않았다.") |

## 2. 구조 템플릿

### 고객사례 도입이야기 카테고리
```
1. 💡 고객사례 Summary (3~5줄 요약)
2. 💡 이런 상황이었어요 (Pain point 서술)
3. 💡 에이컷을 알게 된 계기
4. 💡 도입 첫 달, 달라진 것들 (Before→After 수치)
5. 👀 같은 고민을 하고 계신가요? (CTA)
6. aicut.co.kr 무료상담 신청 + 주소
7. FAQ (2개 정도)
8. 해시태그 (20개)
```

### 일반 칼럼/정보형 카테고리
```
1. 도입부 ("~를 해봤는가" 식 질문/문제제기)
2. 본문 (소제목 2~4개)
3. 핵심 3줄 요약
4. FAQ (2개)
5. 함께 읽으면 도움이 되는 글 (2개 링크)
6. 해시태그 (20~30개)
```

| 요소 | 패턴 |

| 이모지 사용 | 💡 (인사이트 섹션 헤더), 👀 (CTA 섹션) — 그 외 거의 없음 |
