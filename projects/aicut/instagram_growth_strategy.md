## 🎯 3단계 성장 전략

### 1단계: 팔로워 기반 다지기 (1~2주차)

**① 팔로우 정리 (언팔로우)**
- 현재 93명 팔로우 → **45~50명**으로 정리
- 맞팔로우하지 않은 계정 언팔로우
- 이유: 인스타 알고리즘은 **팔로워 대비 팔로우 수가 많으면 신뢰도 ↓**
- 방법: 한 번에 많이 하면 정지 위험 → **하루 10~15명씩**

**② 바이오 최적화**
- 현재: `AI + 전담 에디터까지 영상 편집 전문 스튜디오`
- 제안:
```
🎬 영상 편집 아웃소싱 | D+1 납품
✂️ 숏폼/릴스/쇼츠 월정기 편집
👇 무료 샘플 편집본 신청
🔗 aicut.co.kr
```
- **링크 클릭 유도** → CTA 강화

**③ 릴스 업로드 주기 확립**
- 현재: 11개 게시물 (대부분 카드뉴스)
- **릴스가 도달률 10배 높음**
- 주 3회 릴스 업로드 (월~수~금)
- 내용: 제품 편집 Before/After 15초, 꿀팁, 고객 사례

---

### 2단계: 도달률 확대 (2~4주차)

**④ 해시태그 전략 고도화**

현재: 12개 카테고리 → **소분류 + 대분류 조합**

| 유형 | 예시 | 용도 |
|:-----|:-----|:------|
| 대분류 | #영상편집 #영상편집외주 | 넓은 도달 |
| 중분류 | #쇼핑몰영상 #병원릴스 | 타겟 도달 |
| 소분류 | #스마트스토어영상 #치과릴스 #부동산숏폼 | 전환율 ↑ |
| 지역 | #송파영상편집 #강남영상제작 | 지역 타겟 |
| 브랜드 | #에이컷 #aicut | 브랜딩 |

**⑤ 타겟 계정 댓글 활동 강화**
- 현재: 해시태그 검색 후 댓글 (8개/회)
- **타겟 계정의 게시물에 의미 있는 댓글** → 프로필 방문 유도
- 경쟁사 계정, 관련 업종 계정 팔로워들에게 댓글

**⑥ 콜라보/멘션 전략**
- 관련 업종 계정과 상호 멘션
- 소규모 인플루언서에게 제품 리뷰 의뢰 (샘플 편집 제공)

---

### 3단계: 전환율 최적화 (1개월~)

**⑦ 릴스 → 프로필 → 홈페이지 퍼널 구축**
```
릴스 시청 (15초) → 프로필 방문 → 바이오 링크 클릭 → aicut.co.kr
```
- 각 릴스 마지막 2초: **"프로필 링크 클릭"** 문구 + 화살표

**⑧ 무료 샘블 CTA 인스타 적용**
- 바이오: "무료 샘플 편집본 신청 → aicut.co.kr"
- 각 게시물 댓글: "샘플 편집본 필요하시면 프로필 링크로!"

**⑨ 인사이트 분석**
- 주 1회 인스타 인사이트 확인
- 어떤 릴스/게시물이 도달률 높은지 분석
- 성과 좋은 콘텐츠 유형 집중
