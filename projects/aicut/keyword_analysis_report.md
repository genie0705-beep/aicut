## 🚀 액션 플랜

**즉시 (금주):**
1. 온라인 강의 포스팅 발행 완료 (오늘 시도했으나 실패, 정이사님께 요청)
2. 프랜차이즈 포스팅 발행 (초안 + 에디터 입력 완료)
3. 네이버 서치어드바이저 수동 수집 요청 (발행 후 즉시)

**단기 (1~2주):**
- 메인 키워드별 시리즈 3편씩 작성
- `영상편집외주` → 3편 추가 (현재 2편)
- `숏폼제작` → 2편 추가 (현재 1편)

**중기 (1개월):**
- 총 포스팅 20개 목표 (현재 14개)
- 경쟁 낮은 블루오션 키워드 5개 추가 공략
- 블로그 조회수 2배 목표
